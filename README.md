# Muhammad Sabir Riaz — Portfolio

GitHub Pages-ready static portfolio website.

## Publish

1. Create a public repository named `YOUR-GITHUB-USERNAME.github.io`.
2. Upload all files in this folder to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/(root)`.

Your site will be published at `https://YOUR-GITHUB-USERNAME.github.io`.
